# fishspikes

This GitHub repository contains the code developed during a hackathon organized by [SmartNets](www.smartnets-etn.eu). 

The hackathon aimed to encourage participants from diverse backgrounds to apply their unique analytical approaches to new types of data. The underlying premise was that network analysis at different levels, such as proteins, neurons, and organisms, shares inherent similarities, regardless of the data type.

The code in this repository is a practical application of this concept, where techniques typically used in neuroscience for analyzing neuronal spike trains are applied to behavioral [data](https://datadryad.org/stash/landing/show?id=doi:10.5061/dryad.sbcc2fr2h) from fish.

This project is a work in progress and we welcome any contributions or suggestions.
